# ViewImage 双栏图像查看器与工业对比工具

**ViewImage** 是一款专为**视觉算法效果对比、工业缺陷检测、前后处理图像复核与数据集清洗标注**设计的高性能双栏图像查看器。

提供**智能配对同步翻页（模式 A）**与**独立翻页（模式 B）**两种工作流，并深度集成了**单张/批量安全拷贝与剪切**、**防覆盖递增重命名**、**实时色彩取样探针**以及**可折叠带搜索的文件列表**。

---

## 🌟 核心特性

- 🎨 **专业钛黑质检深色主题**：针对长时间工业质检与图像复核打造，抗视觉疲劳，高对比度现代化控件。
- 🖼 **高性能无级图像画板**：
  - 滚轮以鼠标光标为中心自由缩放（支持 `0.02x ~ 64x` 范围，4x 以上保留像素邻近无损采样便于查看锯齿）。
  - 按住鼠标左键任意平移画布。
  - 双击画板快速自适应窗口大小，支持 `1:1` 原图物理分辨率显示。
  - 画板右下角常驻当前缩放比例 HUD（如 `100%`、`150%`、`33%`）。
  - **左右视口联动（Link Views）**：开启后，缩放倍率与平移偏移量在两侧保持严格绝对同步。
- 🤖 **智能配对规则引擎（模式 A）**：
  - **双样本智能推断**：只需在左右两侧各挑选 2 对确认对应的样本图像，算法自动推断并展示匹配规则。
  - **多规则表达式支持**：
    - `same`：主文件名（忽略扩展名）相同
    - `same_ext`：包含扩展名的完整文件名完全相同
    - `prefix:N`：文件名前 N 位相同
    - `suffix:N`：文件名后 N 位相同
    - `number`：文件名中的所有数字串按顺序相同
    - `strip:左前|左后|右前|右后`：去除固定前后缀后相同
    - `regex:PATTERN`：正则表达式提取对应键（优先取第 1 捕获组）
  - **即时预览**：三步式向导实时预览可配对数与未匹配数；未匹配图像在列表中亮红（`#f87171`）标注。
- ✂️ **单张与批量文件流转（拷贝 / 剪切）**：
  - **单张操作**：
    - `📋 拷贝`（`Ctrl+C` / `Ctrl+S`）：将当前悬停侧（或左侧）图像原样复制到输出目录。
    - `✂ 剪切`（`Ctrl+X`）：将当前图像移动至输出目录，**并自动无缝跳转加载下一张（或下一对）图像**，极速挑选与剔除 NG 样本。
  - **复选框批量勾选**：
    - 侧边抽屉列表中每项自带复选框，输入关键字实时过滤时不丢失勾选状态。
    - 批量工具栏提供 `☑ 全选`、`□ 清空`、`反选`、`已选: N` 动态计数、`📋 批量拷贝` 与 `✂ 批量剪切`。
  - **模式 A 成对联动勾选**：单列直接呈现 `图片A ↔ 图片B` 配对行，一键批量双侧成对处理。
  - **⚠️ 目标目录重名智能冲突提醒**：
    - 当目标输出目录已存在同名文件时，弹出专属冲突提示弹窗。
    - **单文件冲突**：支持选择「自动递增重命名 (追加 _1)」、「覆盖目标文件」或「取消」。
    - **批量冲突**：支持一键「全部递增重命名」、「全部跳过已存在」或「全部覆盖」，彻底杜绝误操作。
- 📋 **极致轻量布局与空间最大化**：
  - **单行流线型顶栏**：高度压缩至 36px，集成路径胶囊、模式切换、居中全局翻页与视口工具。
  - **左侧抽屉式文件列表**：支持 `F3` 一键展开/收起，收起后垂直高度 100% 留给图像画板。
  - **按需图像调色**：点击「🎛 调色」按需展开亮度/对比度调节条，平时 0 像素占位。
  - **沉浸式画板**：左上角半透明悬浮胶囊标签显示当前文件名与侧别，无厚重边框堆叠。
- 🎛 **实时无损显示滤镜与物理取色探针**：
  - 左右两侧支持独立的黑白灰度开关，以及亮度与对比度无损调节（`-100 ~ +100`），仅在渲染层动态变换，不修改原始文件。
  - **实时色彩探针 (Color Swatch)**：状态栏右侧跟随光标实时显示 `(X, Y) 坐标 ｜ 灰度 ｜ RGB #HEX`，并绘制对应真实物理颜色的方块色块。
- 📁 **拖放交互与状态记忆**：
  - 支持直接将系统文件夹或图片拖拽到画板上快速设定路径。
  - 顶部 `⇄ 互换` 按钮一键对调左右源目录。
  - 配置（路径、模式、规则、联动状态等）自动持久化至同目录 `viewer_config.json`。
- ⚡ **零笨重第三方库依赖**：
  - 不依赖 OpenCV、Pillow、numpy 等臃肿依赖，图像加载走 Qt 原生图形管线，启动极快。

## 🛠️ 环境依赖与安装

### 1. 系统要求
- Python 3.8 及以上版本
- 操作系统：Windows / Linux / macOS

### 2. 安装依赖
本项目仅需安装 Qt 绑定库（**PyQt5**、**PyQt6** 或 **PySide6** 任选其一均可完美兼容）：

```bash
# 使用 pip 安装依赖
pip install -r requirements.txt

# 或如果使用 Conda 环境：
conda create -n qtUI python=3.10
conda activate qtUI
pip install PyQt5
```

## 🚀 启动与使用

在项目根目录下直接运行：

```bash
python dual_image_viewer.py
```

## 📂 项目结构

```text
ViewImage/
├── dual_image_viewer.py        # 顶层启动入口脚本（保持 100% 向后兼容）
├── requirements.txt            # 项目依赖说明
├── README.md                   # 项目使用与技术说明文档
├── viewer_config.json          # 运行配置记忆文件（路径、模式、规则等）
├── test_view_image.py          # 包含 19 项用例的自动化测试套件
└── view_image/                 # 模块化核心包
    ├── core/                   # 核心算法与工具
    │   ├── qt_compat.py        # Qt 跨版本统一兼容层（PyQt5 / PySide6 / PyQt6）
    │   ├── file_ops.py         # 拷贝剪切、重名检测、冲突策略（重命名/覆盖/跳过）与批量处理
    │   ├── rules.py            # PairRule 规则引擎、配对算法与样本推断
    │   ├── scanner.py          # 图像文件扫描与自然排序（img2 < img10）
    │   └── config.py           # 配置读取、原子写入与格式校验
    ├── widgets/                # UI 视图与控件
    │   ├── styles.py           # 钛黑专业深色主题样式表 (QSS)
    │   ├── image_view.py       # 沉浸式自绘图像视口、悬浮胶囊标签与像素探针
    │   ├── sidebar_drawer.py   # 统一左侧抽屉文件列表、模式 A 配对行与批量操作条
    │   ├── adjustment_bar.py   # 按需展开的图像黑白与亮度对比度调色条
    │   ├── conflict_dialog.py  # 目标目录重名文件冲突提醒与决策对话框
    │   ├── path_dialog.py      # 路径设置弹窗
    │   ├── side_panel.py       # 兼容面板代理组件
    │   ├── rule_dialog.py      # 三步式配对规则配置向导
    │   └── help_dialog.py      # 快捷键与使用手册弹窗
    └── main_window.py          # 极简单行顶栏主窗口控制中枢
```
